Domain Risk Scan

Run a lightweight external exposure assessment for a domain and receive a structured snapshot across DNS, TLS, email-security configuration, and selected public-facing signals.

This tool is intended for fast triage and documentation support. It does not replace a full penetration test, audit, or compliance assessment.

Example inputs: example.com, openai.com, yourcompany.it
Full report available

The preview shows the top findings only. The full report includes the executive summary, complete evidence, remediation priorities, and PDF export when available.

What it checks

SSL/TLS

Certificate and TLS-related visibility checks where externally available.

DNS

Selected DNS checks and common misconfiguration patterns affecting domain hygiene.

Email Security

Basic visibility into MX, SPF, and DMARC-related issues where available.

Exposure Signals

External signals that help surface domain-level exposure and visible risk indicators.
