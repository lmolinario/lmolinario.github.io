OpenGovSec Toolkit

OpenGovSec Toolkit is a modular cybersecurity and digital-governance project for passive, reproducible analysis of public-sector open-data metadata, API documentation, and repository readiness.

It is designed as a portfolio-grade case study: public data sources, transparent checks, documented risk scoring, Markdown reports for human review, JSON outputs for automation, and CSV summaries for dashboards or CI artifacts.

Open GitHub repository Methodology Risk model

Current MVP scope

The project currently implements a strong open-data scanner, plus base modules for API documentation and repository readiness. The next evolution is to specialize these bases into a PDND/API security checker and a public-administration software supply-chain radar.

Open Data Risk Scanner

Assesses CKAN-like public metadata, resource declarations, descriptions, ownership, reuse signals, and risk scoring.

Mature MVPdati.gov.it

API Documentation Checker

Base module for checking OpenAPI-like documentation, server declarations, paths, operation descriptions, and documentation completeness.

Base modulePDND direction

Repository Readiness Checker

Base module for reuse and maintainability signals such as license, README, dependency manifests, CI, contribution files, and repository activity.

Reproducible workflow

The core value of OpenGovSec is not only the scanner, but the traceable chain from public metadata to human-readable and machine-readable outputs.

public catalogue metadata → local JSON source → passive scanner → Markdown report → JSON report → CSV summary

Direction

OpenGovSec is being developed as a single modular toolkit rather than a collection of unrelated scripts.

Specialize the API documentation checker toward PDND/API security documentation signals, and extend repository readiness into a public-administration supply-chain radar.
